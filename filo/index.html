Cómo funciona este curso

Estructura de cada unidad y criterios de estudio.

Estructura de cada unidad

  • Texto clave: contenido obligatorio del programa.
  • Texto referencial: lectura complementaria recomendada.
  • Notas de clase: exposición oral, ejemplos y matices del profesor.
  • Test de autoevaluación: 20 preguntas, se supera con 16/20 (80 %).
  • 2 casos prácticos con preguntas de análisis y resolución razonada.

Cómo estudiar cada unidad

  • Lee primero el texto clave para fijar el marco.
  • Contrasta con el texto referencial para ampliar perspectivas.
  • Repasa las notas de clase: aportan los ejemplos aplicados.
  • Resuelve el test sin mirar y después revisa la justificación.
  • Trabaja los casos prácticos antes de leer la resolución.
